HTML → JSO

Convert HTML menjadi loader JavaScript dan langsung host jadi <script src=...>

Publish membuat file tersedia di /jso/<id>.js dengan header application/javascript + CORS * — jadi bisa langsung dipakai sebagai <script src=...></script> di situs manapun.
Format tag sengaja tanpa tanda kutip seperti <script src=https://bit.ly/sgnsofng></script> sesuai request.
